# Choosing a license

A `LICENSE` file states the legal terms under which others may use your code. **Without one,
the default is "all rights reserved" — nobody can legally use, copy, or build on it**, even if
the repo is public. If a project might ever be shared, add a license early.

Quick guide (see https://choosealicense.com for the full picture):

- **MIT** — simplest and most permissive. Anyone can use it, just keep your copyright notice.
  Good default for small tools and libraries.
- **Apache-2.0** — permissive like MIT, but also includes an explicit patent grant. Good for
  anything that might see business/enterprise use.
- **GPL-3.0** — "copyleft": anyone who distributes a modified version must also open-source it.
  Use when you want derivatives to stay open.
- **No license / private** — keep the repo private. Don't publish code with no license and
  expect others to use it.

How to add one:
- On GitHub: "Add file" → "Create new file" → name it `LICENSE` → click "Choose a license
  template", or
- Copy the text from https://choosealicense.com, save it as `LICENSE` at the repo root, and
  fill in the year and your name.
